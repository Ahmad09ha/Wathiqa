# وثيقة | Wathiqa — Arabic Interface & Design Handoff

Updated: 2026-11-05

## Implemented

- Application UI in Arabic with `<html lang="ar" dir="rtl">`. User-entered contract body text is never machine-translated.
- A right-hand fixed desktop sidebar (`height: 100dvh`), independently scrollable navigation, working RTL anchor links and a mobile right-side drawer.
- The official `lenis` npm package via `lenis/react` root integration, with anchors, reduced-motion support and nested scroll opt-out for independent UI regions.
- Arabic toast notifications for network failures, uploads, validation problems, conflicts and success. Toasts animate on entry and exit, auto-dismiss, and are manually dismissible.
- A custom Arabic delete confirmation dialog in place of the browser's English `confirm()` popup.
- Warm-neutral / muted evergreen visual system, local Arabic fonts, refined typography, balanced two-column cards, and grouped document-toolbar controls.
- Arabic editor labels and navigation; English/Chinese legal content remains unchanged.
- Product branding: وثيقة (Wathiqa), custom favicon, `wathiqa-web` package and `Wathiqa.Api` backend.

## Notes

- This is a local-only MVP. Do not expose it publicly without authentication/authorization, production database migrations, and stronger import security.
- Imported PDF and Word content is heuristic field extraction and does not preserve exact layout.
- On the user's Windows computer, start with `powershell -ExecutionPolicy Bypass -File .\start.ps1` and open http://localhost:3000.
